# A&S Law — marketing site

Corporate law firm landing page built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS v4**.

## Develop

```bash
npm install
npm run dev
```

## Deploy to GitHub Pages

1. In the GitHub repository, open **Settings → Pages**.
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Choose branch **`gh-pages`** and folder **`/`** (root), then save.

From this project directory:

```bash
npm install
npm run deploy
```

This runs a production build with asset base path `/A-S_LawFirm.io/` and pushes the contents of `dist` to the `gh-pages` branch.

The published URL will be `https://astridbonoan.github.io/A-S_LawFirm.io/` unless you add a custom domain in Pages settings.
